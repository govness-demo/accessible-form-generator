# Accessible form generator

Turns a form description into an accessible, multilingual web form that meets WCAG 2.2 AA.

## Overview

Agents describe the fields; the plugin returns tested, accessible markup with labels, errors and translations.

## Interfaces

Protocol: `other`. Languages: en, es, fr.
